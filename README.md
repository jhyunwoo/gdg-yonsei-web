# GDG-Yonsei-Web
Google Developer Group on Campus Yonsei 소개 웹사이트

## 웹 구성
- Home Page
- Team Page
- Member Page
- Session Page
- Project Page
- Admin Page

## 기술 스택
- TypeScript
- React
- Next.js
- Tailwind CSS
- NextAuth

## 실행 방법
1. 패키지 다운로드
   ```bash
    yarn install
    ```
2. Prisma 생성
    ```bash
   yarn generate
   ```
3. DEV
    ```bash
   yarn dev
   ```
